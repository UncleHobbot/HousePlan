# HousePlan

Глоссарий веб-приложения для планирования расстановки мебели. Слова, которые в
проекте значат что-то конкретное. Пользуемся только ими, чтобы в разговорах и
документах речь всегда шла об одном и том же.

## Language

**Помещение**:
Часть проекта — комната, которую обводит один замкнутый контур. У каждого
помещения свой независимый контур: общая стена двух помещений рисуется в каждом
из них отдельно.
_Avoid_: комната, рум

**Контур**:
Замкнутая линия из точек и прямых стен, обводящая помещение. Без дуг, без
самопересечений, дырок внутри нет.
_Avoid_: полигон, фигура

**Стена**:
Прямой отрезок контура между двумя соседними точками. Стены могут идти под
любым углом, не только 90°.
_Avoid_: перегородка, перекрытие

**Точка**:
Место на контуре, где стена заканчивается или разрезана: угол помещения либо
отметка, поставленная на стену вручную. На углах точки появляются
автоматически, на стену ставятся вручную разрезанием стены на две.
_Avoid_: вершина, узел

**Участок**:
Цепочка стен между двумя любыми точками контура — именно к нему прикладывают
размер («от точки А до точки Б — 250 см»). Одна стена — частный случай.
_Avoid_: отрезок, сегмент

**Замок**:
Точный размер, прибитый к участку вручную. Замок не двигается при пересчёте
геометрии; снимается только по воле человека.
_Avoid_: фиксация, закрепление, ограничение
