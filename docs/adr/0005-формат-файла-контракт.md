# Формат файла проекта — внешний контракт

Файл `план.json` читают не только программа, но и внешние агенты (AutoClaw:
3D-модель снэпшота, разбор расстановки по эргономике, пополнение склада —
см. `docs/модель-данных.md`, раздел «Импорт»). Поэтому формат —
задокументированный контракт: в начале файла хранится версия формата (первая
версия — 1); любое изменение схемы увеличивает её и сопровождается строчкой в
`docs/модель-данных.md`. Отдельная «выгрузка для агентов» не строится — файл и
есть выгрузка.

Почему: ADR 0003 выбрал файловое хранение во многом ради агентной доступности
данных; дублирующий формат удваивал бы работу и расходился бы с основным.
Цена решения: свободный рефакторинг схемы ограничен — каждое изменение
становится изменением контракта.
